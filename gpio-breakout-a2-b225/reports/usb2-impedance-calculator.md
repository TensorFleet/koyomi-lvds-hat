# USB2 manufacturing geometry reference

**Native stackup corrected on 2026-09-09.** The saved copper/dielectric
construction matches the profile below; see [native readback](stackup-qualification.json).
The corrected source still must not be described as a fully qualified 90-ohm
channel: breakouts, B-contact stubs and interrupted coplanar ground remain.

Read from the official [JLCPCB impedance calculator](https://jlcpcb.com/pcb-impedance-calculator)
on 2026-09-09. The [published stackup table](https://jlcpcb.com/impedance)
supplies the dielectric dimensions and dielectric constants.

Calculator inputs: rigid PCB, four layers, nominal 1.6 mm, outer copper 1 oz,
inner copper 0.5 oz, units mm. Selected profile **JLC04161H-7628**, standard,
finished thickness **1.59 mm ±10%**. A coplanar differential pair on L1,
referenced to L2, target **90 ohms**, trace edge spacing **0.20 mm**, and
trace-to-coplanar-ground spacing **0.25 mm**, returns trace width **0.2774 mm**.
The displayed rounded output gaps are 0.1999 and 0.2499 mm.

This is a geometry reference for the main outer-layer pair, not measured
impedance or USB compliance. Pad escapes, reversible-contact branches and
vias are discontinuities. L3 branches require their actual L4 ground return
to be reviewed. Manufacturing must confirm the selected materials and
finished geometry; the calculator's displayed 0.5% numerical tolerance is
not a fabrication impedance guarantee. The complete cable/FFC/peer channel
still needs qualification. No fabrication output was generated by this check.


**Implementation limit:** the native flat solder-mask layer uses JLC's 15.24 µm
above traces and Er 3.8; its calculator also models 30.48 µm above substrate
and between traces. The inherited loss tangent of 0.02 is unqualified.
See [remaining qualification results](stackup-and-qualification.md).
