# GPIO A2 manufacturing review — 2026-09-09

The user selected **low-power USB2 bench use**. Retain F2 at 0.5 A; this is not authorization to draw the combined board's 1.5 A fuse rating from a normal USB2 host. Full downstream USB-A loading is outside this adapter's intended scope. This review does not release the board for manufacture or qualify a safe assembled load.

## Confirmed repair

J1's 40 signal pads and two SMT mounting pads lacked F.Paste. The native board now includes paste on all 42 pads, and the incorrect Hirose description is corrected to Samtec. The local library is repaired too. The board's copper, numbered pads, traces, vias, and other footprint geometry match the published pre-repair source. Native DRC has zero errors, zero unconnected items and six existing library warnings. The schematic was not changed.

The local footprint library was rebuilt with KiCad's native serializer from the native IPC snapshot because the available older library loader cannot read the previous experimental format. All 42 local pad positions/sizes/numbers, nine line segments, and the existing nominal envelope model were carried into the new library. The board itself remains in its existing native version and was edited through that version's API. The nominal model still cannot qualify latch or cable fit.

Samtec's [Rev E footprint drawing, figures 1 and 3](https://suddendocs.samtec.com/prints/zf5s-xx-xx-xx-wt-xx-footprint.pdf) uses matching copper/paste apertures: 0.30 by 1.60 mm contacts and 2.24 by 3.12 mm mounting pads. It specifies a 0.15 mm stencil, whereas [product specification section 6.3](https://suddendocs.samtec.com/productspecs/zf5s.pdf) recommends 0.13 mm. Reconcile that process discrepancy with the assembler before releasing the stencil; do not state that both documents specify 0.13 mm.

## Assessment of the eight findings

| Finding | Assessment and disposition |
| --- | --- |
| 1. Missing paste | Confirmed and repaired on GPIO A2 board and local library. The original library is also present in A2, B2.25, B2.27 and C1 checkouts; those board instances and libraries need the same repair in their own active work. They were not modified here. |
| 2. F2 and downstream load | Valid power-budget concern. Retain 0.5 A for the user's bench scope. Hold current is not a regulated current ceiling, and ambient temperature affects it. At an assumed 0.75 ohm resistance, 0.5 A causes 0.375 V drop; actual downstream voltage also depends on source voltage, resistance, cable and load. A downstream 1.5 A fuse does not grant a USB host power allowance. [USB-IF](https://compliance.usb.org/index.asp?Format=Standard&UpdateFile=Policies) limits a standard USB2 downstream port's peripheral load to 500 mA; configuration and hub budgeting still matter. |
| 3. Narrow power routes | Substantially confirmed: most power segments are 0.20 mm; USB_VBUS also contains 0.25 mm segments. LCD 5 V and 3.3 V paths use In2.Cu. Correction: the saved stack specifies 35 micrometre copper on every copper layer; 15.2 micrometre inner copper belongs to the intended JLC profile, not the saved board. A single width-to-current number does not qualify these paths. Widen principal rail runs, retain only necessary short fanouts, and recalculate voltage drop/thermal rise for the actual stack and bench load. Not changed by this paste-only repair. |
| 4. DPI source termination | No source arrays on this adapter. Source-side resistor options are a sensible layout improvement for the 22 driven DPI nets (18 RGB, clock, HSYNC, VSYNC, enable). Six isolated four-resistor arrays would cover them with two unused channels. Receiver-side 47 ohm arrays do not provide source termination for the upstream cable. Final values depend on driver impedance and channel behavior; zero-ohm options alone do not terminate the line. Not added or qualified in this repair. |
| 5. USB B-contact routes | Existing native path audit gives A+ 22.441 mm, A- 21.139 mm, B+ 28.090 mm, B- 29.885 mm; B paths use two vias. Thus B-A excess is about 5.65 mm and 8.75 mm. These endpoint-length differences are not the branch-point-to-unused-contact stub lengths, and do not establish a 480 Mb/s pass/fail limit. Measure the actual branches and qualify the channel. A 16-contact receptacle still normally exposes A6/A7 and B6/B7; a better footprint may shorten joins but does not automatically eliminate them. Connector replacement not made. |
| 6. Stackup | Confirmed open release blocker: native dielectric layers remain 0.48/0.48/0.48 mm, inconsistent with the intended JLC04161H-7628 calculation. No verified 90 ohm claim. Prior native setter and GUI access failures remain unresolved; no text-based native-source rewrite was substituted. |
| 7. Inrush | Confirmed system concern. C1's saved native netlist has 120.2 microfarad directly on its fused VBUS rail before counting further loads. Fuses and an ideal diode do not establish controlled inrush. [TI explains that LM66100 does not have inrush-current protection](https://e2e.ti.com/support/power-management-group/power-management/f/power-management-forum/869783/lm66100-lm66100-output-capacitance). Bench-only steady-state use does not remove plug-in charging. Review the actual power tree and capture inrush/host droop; add controlled charging if required. No scope measurement was performed. |
| 8. Wrong description | Confirmed and repaired on GPIO A2's embedded and library footprint. |

These findings do not demonstrate a pin-order error. They do establish unresolved assembly, power and signal-integrity work. Items 1 and 8 are repaired here; the remaining layout and qualification work is not represented as complete. No Gerber, drill, BOM, CPL, or fabrication package was generated or uploaded.
